FV360 STUDIO - ACTUALIZACIÓN DE ANOTACIONES / CATEGORÍAS
======================================================
CAMBIOS AÑADIDOS SIN CAMBIAR EL MOTOR EXISTENTE

1. Panel OBJETOS y acceso en la barra de herramientas:
   - RECTÁNGULO / CÍRCULO: selecciona y arrastra sobre la fotografía.
   - NOTA: escribe en el campo de texto, selecciona Nota y toca dónde ubicarla.
   - IMAGEN PNG: pulsa Elegir imagen PNG del equipo (máximo 12 MB), luego toca
     el lugar sobre la fotografía. Solo archivos PNG válidos.
   - EDITAR OBJETOS: selecciona el elemento y arrástralo para moverlo; arrastra
     la esquina inferior derecha para ajustar su tamaño. Usa Eliminar objeto.
   - Las formas son representativas, NO contienen medición de área ni longitud.
   - Puedes cambiar el color del borde y el tamaño de texto.

2. Panel CAPAS: sección para crear categorías personalizadas, con nombre y color.
   Aparecen en Dibujo, Capas, Totales, CSV y tabla DXF. No se eliminan las
   categorías predeterminadas de C.D., C.A., Tierra, etc.

3. EXPORTACIONES:
   - PNG: opción independiente para incluir / ocultar formas, notas e imágenes.
   - Editor de láminas y reporte: control independiente para mostrar objetos.
   - JSON / ZIP: se guardan las categorías propias y los objetos de cada foto,
     incluidas imágenes PNG superpuestas.
   - DXF: conserva el comportamiento anterior, exporta la tabla de longitudes
     y agrega las categorías propias. Las formas representativas NO generan
     geometría CAD ni afectan los totales.

SEGURIDAD / DATOS
   El proyecto sigue funcionando localmente. Los archivos PNG se guardan como
   datos del proyecto, no se envían a servidores de FV360. No publiques fotos
   de clientes ni respaldos JSON/ZIP en un repositorio GitHub público.
